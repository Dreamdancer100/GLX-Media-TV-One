## ✨ Features

- 🚀 **No server needed:** Runs on its own on Android TV and Google TV.
- 🧩 **Your sources:** USB hard drive, USB stick or FritzBox NAS.
- ⚙️ **Covers and resume:** Covers for your media and resume playback.
- 🔒 **Made for the TV:** Fully usable with the TV remote.
- 📂 **Phone as remote:** Works with GLX Remote for Android and iPhone.
- ⚡ **One-time purchase:** 19.99 EUR once, no subscription.
